Random Users Directory
A React-based user directory application that fetches random user data from the FreeAPI Random Users API and displays it in a clean and responsive card layout.
Features


Fetch random users from API


Responsive user card layout


Display user profile images


Show user details:


Name


Email


Phone


Username


Age


Location




Loading state handling


Error handling


Refresh users button


API Used
API Endpoint:
https://api.freeapi.app/api/v1/public/randomusers
Tech Stack


React


JavaScript


CSS


Project Structure
src/│├── App.jsx├── index.css└── main.jsx
Installation
Clone the repository:
git clone <your-repository-link>
Move into the project folder:
cd random-users-directory
Install dependencies:
npm install
Start the development server:
npm run dev
